AdRoast for Claude

Roast B2B ads and the landing pages behind them without leaving Claude. Ask Claude to score an ad against its buyer, pull a company's live LinkedIn and Google ads worst first, or open a report you already ran.

What you need

An AdRoast account. Sign-up is free with Google or a work email, and the free plan includes one full roast. Each roast_ad call uses one roast from your plan, the same as a roast on the website. Paid plans are on adroast.in.

Connect it

From the Claude directory: open Settings, then Connectors, find AdRoast and click Connect. Claude opens an AdRoast sign-in page; sign in with Google or an emailed link, then click Allow.

As a custom connector: in Claude go to Settings, Connectors, Add custom connector, and use this URL. Claude takes you through the same sign-in.

https://www.adroast.in/api/mcp

Claude Code:

claude mcp add --transport http adroast https://www.adroast.in/api/mcp

Scripts and other MCP clients can skip the sign-in and send a personal API key instead (AdRoast, My Account, API & MCP) as Authorization: Bearer ak_....

To disconnect, remove the connector in Claude. Regenerating your API key in My Account cuts off every script that uses it.

Tools

roast_ad (writes a report): scores an ad and its landing page against the buyer it should reach. Give it the landing_url, plus the ad image URL and/or ad copy if you have them, and either the icp or the company website so AdRoast can infer the buyer. It returns the overall score, the ICP mismatch, ranked issues, the landing page score, a recommendation, and a link to the full report. If there is no readable landing page, or no buyer can be inferred, it asks for that instead of guessing.

list_live_ads (read only): give it a company website and it pulls that company's live LinkedIn and Google ads, scores each one against the inferred buyer, and lists them worst first with the fix for each.

get_report (read only): opens a saved roast by its report id, the id in an adroast.in/?id=... link.

Try asking

"Pull semgrep.dev's live ads and tell me which one wastes the most budget."

"Roast this LinkedIn ad. Landing page https://example.com/demo, the copy is: ... It targets heads of AppSec at Series B SaaS."

"Open report abc123 and turn the fixes into three new headlines."

Not using Claude?

The same roasts run on AdRoast on Apify Store: pay per company or per ad, from the Apify console, its API, or any automation that calls Apify. Or roast directly on adroast.in.
